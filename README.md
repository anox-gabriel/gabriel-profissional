# Portfólio · Gabriel Soares

Site portfólio (PT/EN) na identidade Grid Oculto. Next.js + Tailwind v4 + Motion.

- Rodar local: `npm install` e `npm run dev` (http://localhost:3000)
- Trabalhos: `lib/data.ts` (sites e criativos). Imagens em `public/work/` (webp, 900px; sites também com `-full` de 1440px)
- Textos PT/EN: `lib/i18n.tsx`
- Deploy: Vercel (push na `main` publica)
