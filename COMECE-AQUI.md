# Comece aqui (computador novo)

1. Instale o **VS Code** + a extensão **Claude Code** e entre com o seu Gmail pessoal.
2. (Opcional, para Reels e para o site) Instale o **Node.js**.
3. Extraia o RAR em uma pasta, por exemplo `C:\Gabriel - Profissional`.
4. No VS Code: **File → Open Folder** → escolha essa pasta.
5. Abra o Claude Code e cole o prompt abaixo.

---

## Prompt para colar

```
Esta pasta é o meu workspace de design (Gabriel Soares). Configure este computador para trabalhar exatamente como no meu outro PC:

1. Leia o CLAUDE.md da raiz inteiro. Ele tem todas as regras de trabalho (estrutura de pastas, cliente novo, specs, referências, insights, formatos, custo no Magnific, Reels). Siga sempre essas regras.
2. Leia o perfil.md (quem eu sou, LinkedIn) e Clientes/Grid Oculto/marca.md (minha marca).
3. Leia todos os arquivos em _claude/memory/ e salve na sua memória persistente deste projeto as preferências que valem para mim aqui: idioma pt-BR, formato padrão de criativo 1080x1350, custo do Magnific (~60 créditos, medium, máx. 2k), edição de Reels local (eu faço os cortes) e o workspace Gabriel Profissional. Ignore as memórias que são só de clientes da V4 (In Natura, Japão da Construção, Dr. Messias, Drive G: da V4) e a estrutura V4.
4. Me diga quais ferramentas faltam neste PC (Node.js, Git) e o que cada uma é usada para.
5. No final, me mostre um resumo curto: estrutura que você encontrou, clientes existentes e como eu crio um cliente novo.
```

---

## Depois, no dia a dia

- **Cliente novo:** "cliente novo: Nome do Cliente" + logo, cores, Instagram/site.
- **Demanda nova:** "nova demanda para <Cliente>: ..." → o Claude cria a spec, você aprova, ele produz.
- **Ideia solta:** "anota no inbox: ...". Sexta: "organiza o inbox".
- **Conectores** (Google Drive, Magnific, v0, Chrome) são ligados por conta/computador: em claude.ai → Settings → Connectors com o seu Gmail pessoal; o MCP do Magnific precisa ser configurado de novo neste PC.
