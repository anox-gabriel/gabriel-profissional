The In Natura landing pages (LPs) go in https://github.com/gabrieloliveira-v4/innatura (branch `main`). The workspace repo (`claude-workspaces`) is separate. The user set this up on 2026-11-04 and also said some chats are dedicated only to In Natura.

**How to apply:** In an In Natura chat, work inside `V4 - Company/Clientes/In Natura/` (see [[v4-workspace-estrutura]]). Commit and push LP code to the innatura repo, never to claude-workspaces. The `gh` CLI is not installed; use plain git.
