Quando o usuário pedir "criativo" ou "criativo para Instagram", o formato padrão é 1080×1350 px (4:5), para todos os clientes. Só muda se ele escrever outras dimensões no pedido.

**Why:** Pedido explícito do usuário em 2026-11-04, para não ter que repetir o formato.
**How to apply:** Usar 1080×1350 na spec (tabela Peças e formatos), na geração de imagem e na exportação. Também registrado no `V4 - Company/CLAUDE.md`. Ver [[v4-workspace-estrutura]].
