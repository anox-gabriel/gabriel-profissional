# Gabriel — Profissional

Workspace pessoal do Gabriel Soares (designer). Mesma lógica do `V4 - Company`, mas o "cliente" principal sou eu: perfil profissional, LinkedIn, portfólio e marca pessoal.
Trabalhos feitos para a V4 entram aqui só como **portfólio** (cópia/referência). As regras e arquivos de cada cliente continuam em `V4 - Company/Clientes/`.

## Estrutura

```
Gabriel - Profissional/
├── CLAUDE.md          ← regras deste workspace (este arquivo)
├── perfil.md          ← dossiê profissional: quem sou, cargo, skills, ferramentas de IA, resultados
├── insights.md        ← o que funcionou no LinkedIn/portfólio (alcance, convites, respostas)
├── referencias.md     ← links: LinkedIn, Drive de portfólio, sites, refs externas
├── _inbox.md          ← ideias soltas
├── _templates/        ← modelos de spec e de cliente (cópia do V4)
├── referencias/       ← material baixado para consulta (não é entrega)
├── specs/             ← uma spec por demanda (AAAA-MM-DD-nome.md)
├── assets/            ← entregas finais, uma pasta por demanda (AAAA-MM-nome/)
└── Clientes/
    └── Grid Oculto/   ← minha empresa (teste); mesma estrutura de cliente do V4
```

## Regras

- Antes de qualquer peça pessoal (banner, post, portfólio), leia `perfil.md` e `insights.md`.
- Toda demanda começa por uma spec em `specs/` a partir de `_templates/spec.md`.
- **LinkedIn:** nunca publicar ou alterar nada no perfil sem aprovação explícita do texto/arte final. Primeiro rascunho na spec, depois aplicar.
- **Claims de IA:** descrever competência com provas (ferramentas, entregas, números reais). Não inventar certificações, cargos ou resultados.
- Formatos: banner LinkedIn 1584×396 px; foto de perfil 400×400 px; post LinkedIn 1080×1350 (padrão) ou 1200×627 (link).
- Custo no Magnific: mesma regra do V4 (~60 créditos/imagem, `medium`, máx. 2k, `simulate_cost` antes).
- Textos em pt-BR; prompts de imagem em inglês.
- **Identidade visual pessoal = paleta da Grid Oculto** (preto `#0A0A0A`, creme `#E5DAC8`, verde-azulado `#26A69A`, vermelho `#B71C1C`) + estética design e mágica (cartas de baralho, naipes, brilhos, grid oculto). Detalhes em `perfil.md` seção 8.
- **Posicionamento:** foco principal é Designer & Web Designer; IA é diferencial (domínio de IA generativa para velocidade e qualidade); vídeo com IA aparece como algo que também faz, não como foco.
